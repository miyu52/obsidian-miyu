# Miyu

个人 Obsidian 工具集，为自己的工作流定制。

## 功能

### 随机文件名

生成随机文件名的笔记，适合草稿、速记、不想想名字的时候。

- **命令：** `生成随机名称笔记`（`generate-random-note`）
- 创建空 `.md` 文件并以随机名称打开
- 可配置字符集：大写字母、小写字母、数字、符号
- 长度可调（1–64 字符）
- 文件名冲突自动重试（最多 3 次）

### 番茄钟

工作/休息循环计时器，与 Obsidian 任务系统深度集成。

- **命令：** `切换番茄钟`（`toggle-timer`）、`切换番茄钟面板`（`toggle-timer-panel`）、`重置番茄钟`（`reset-timer`）、`切换番茄钟模式`（`toggle-mode`）
- **面板：** 侧边栏视图（工作/休息倒计时 + 进度环 + 今日进度），右下角功能区包含任务/设置/统计三个子面板
- **计时：** 工作/休息时长可配置，支持自动开始下一段、暂停/继续、低帧率模式
- **任务追踪：** 从 md 文件解析任务树（按标题分组、嵌套、可折叠），激活任务后每完成一个番茄自动把 `🍅:: n/m` 计数写回任务行；支持 TASKS / Dataview 两种任务格式
- **任务面板：** 今日进度卡片、文件切换、待办/已完成/全部过滤、搜索、活动任务行、右键菜单（打开任务文件 / 标记完成）
- **统计面板：** 本日/本周/本月/总计卡片、单周日分布图、GitHub 风格年度活跃热力图、点击查看每日任务明细
- **通知：** 系统通知 + 提示音（支持自定义音效），会话结束不会被吞掉
- **状态栏：** 可选显示倒计时（左键开始/暂停，右键菜单）
- **持久化：** 会话记录、每日目标、标题展开状态（默认折叠）、过滤条件、活动任务均持久化，重启后恢复；会话记录可存到指定 md 文件（`%% miyu:records` 代码块，可读可编辑）或默认的 data.json

### 国际化

可在设置中切换界面语言，目前支持：

| 语言 | 代码 |
|------|------|
| 简体中文 | `zh-CN` |
| English | `en` |

切换语言后，命令名称、通知和设置界面即时生效。

## 设置

### 通用

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 语言 | 下拉 | 简体中文 | 界面语言 |
| 长度 | 数字 1–64 | 8 | 随机字符串字符数 |
| 大写字母 | 开关 | 开 | 包含 A–Z |
| 小写字母 | 开关 | 关 | 包含 a–z |
| 数字 | 开关 | 开 | 包含 0–9 |
| 符号 | 开关 | 关 | 包含 `!@#$%^&()-_[]{}+=` |

### 番茄钟

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 工作时长 | 数字 1–120 | 25 | 每个工作会话的分钟数 |
| 休息时长 | 数字 0–60 | 5 | 每次休息的分钟数（0 = 一直工作不休） |
| 自动开始下一会话 | 开关 | 关 | 当前会话结束后自动开始下一会话 |
| 启用状态栏计时器 | 开关 | 关 | 在状态栏显示计时器 |
| 低动画帧率 | 开关 | 关 | 降低动画帧率以节省 CPU |
| 使用系统通知 | 开关 | 关 | 会话结束时发系统通知 |
| 声音通知 | 开关 | 开 | 会话结束时播放提示音 |
| 自定义通知音效 | 文本 | 空 | 库内音频文件的路径 |
| 启用任务追踪 | 开关 | 关 | 激活任务时自动添加块 ID，完成会话后写回番茄计数 |
| 任务格式 | 下拉 | TASKS | TASKS（emoji 风格）/ Dataview（内联字段风格） |
| 显示任务番茄计数 | 开关 | 开 | 任务行显示番茄计数与进度渐变 |
| 每日番茄目标 | 数字 0–30 | 0 | 每天计划完成的工作会话数（0 = 关闭） |
| 周起始日 | 下拉 | 周日 | 统计图表的周起始日 |
| 任务文件 | 列表 | 空 | 参与任务追踪的 md 文件 |
| 记录文件 | 文件选择 | 未设置 | 会话记录存储文件（未设置 = data.json；设置后写入该文件的 `%% miyu:records` 块） |

## 安装

### 源码安装

```bash
git clone https://github.com/miyu52/obsidian-miyu.git
cd obsidian-miyu
npm install
npm run build
```

将 `main.js`、`manifest.json`、`styles.css` 复制到仓库的 `.obsidian/plugins/obsidian-miyu/`。

## 开发

```bash
npm install      # 安装依赖
npm run dev      # 监听模式
npm run build    # 生产构建（类型检查 + 压缩）
npm run lint     # 代码检查
npm test         # 单元测试（vitest）
```

需要 Node.js ≥18，Obsidian ≥1.7.2。
